DeepSeek-Reflex — Windows x64 (see VERSION for this package's version)

首次打开会显示四步使用引导，可跳过；设置 → 使用帮助可以重新查看。
点标题栏的客户端名称切换 DeepSeek、豆包、千问或 Kimi。首次使用时按各官网提示登录。
后台启动在首次唤起时加载所选客户端。
Ctrl+Space：唤出 / 收起；Ctrl+Shift+D：选中文字带入，检查草稿后自行发送。
右上角关闭收进托盘，托盘菜单“退出”才会结束程序。
v1.0.17：对话模式栏支持普通、翻译、解释、提问、润色、总结；每条消息可见注入提示词。
唤起时跟随鼠标所在屏幕：换屏居中，同屏保留位置；不会随鼠标移动自动追随。

ZIP: extract the entire DeepSeek-Reflex folder, then double-click DeepSeek-Reflex.exe.
EXE: run the Setup installer; no administrator privileges are required.

Requires Windows 10/11 x64, .NET Framework 4.8 and WebView2 Evergreen Runtime.
Runtime download: https://developer.microsoft.com/microsoft-edge/webview2/

Ctrl+Space: show / minimize the chat window.
Ctrl+Shift+D: import selected text as a draft, then confirm and send yourself.
Settings: customize hotkeys, close behavior, focus and window size.
Getting started: a four-step introduction on first visible launch; replay it from Settings > Help.
Tray right-click: open / pin / settings / exit. Exit before upgrading.

The ZIP is standalone but not data-isolated: both packages keep preferences
and website login under %APPDATA%\cloud.doitbenai.deepseek-reflex.
Uninstall preserves these data. No API key is needed; choose a client in the title bar and sign in on its website.
Each website uses a separate persistent profile.
