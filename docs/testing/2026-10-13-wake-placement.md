# 跟随鼠标唤起：实现与验证

日期：2026-10-13。基线为 `main` / `65768104132e2f0bcf9db92ab6094c24198e503b` 加上当前未提交的持续对话模式改动。本次保留这些改动，未提交、推送、发布或替换本机安装。公开包仍为 v1.0.16。

## 行为

唤起时以鼠标所在屏幕为目标，换屏居中，同屏保留最近的位置和大小。返回旧屏幕也重新居中，不保存每屏历史。已显示的小窗跨屏唤起时移动并显示，同屏可见时仍按原设置最小化或收进托盘。仅唤起时调整，不随鼠标移动自动追随。

唤起键、取词键、托盘打开、已有实例消息及前台启动共用定位规则。取词在异步捕获前记录目标，托盘菜单在 UI 排队前记录目标。设置或引导打开期间继续聚焦原面板，不搬动所有者。

`WakeTarget` 保存触发时的点及显示器身份；身份失效时解析为当前可用屏幕。`WakePlacement` 仅处理目标与逻辑尺寸及纯几何计算。宿主保持同一个 WebView，先跨屏，再结合真实窗口 DPI 校正尺寸与居中。一次队列校正处理延迟 DPI 消息，手动拖动、调整尺寸或切换窗口预设会取消旧校正。位置继续写入原 `webview-bounds.txt`，未新增公开接口、开关或配置版本。
