2026-11-06。修复 BUG-035 入口补丁遗漏的通用文本框聚焦行为，使用共享 EditorTextBox，不修改配置格式、模型路由或官网正文。

| 页面 | 输入控件 | 本轮检查 |
| --- | --- | --- |
| 设置主页 | 唤出键、取词键 | 录入时不全选提示文字，Tab 转移、Esc 退出，面板保持打开 |
| 快捷指令 | 名称、正文 | 示例、首次聚焦、Tab、非法名称聚焦、主动选区和轮廓 |
| 聊天模式 | 名称、提示词 | 编辑、示例、只读复制、非法正文聚焦、选区及滚动恢复 |
| 反馈 | 正文、记忆的联系方式 | 首次聚焦、Tab、失焦轮廓、已有选区、发送失败保全 |
| 帮助、菜单 | 无原生文本输入 | 核对源码控件清单，无此类文本框 |
| 主聊天、快速回答、登录／外链窗 | WebView 中的网页输入 | 核对宿主焦点脚本仅在页面活动且唯一可编辑框时聚焦，不读写草稿或选区；复用既有浏览器证据，不宣称本轮重新登录官网 |
