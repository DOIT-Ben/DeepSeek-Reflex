## 结论与修复

确认的问题按 BUG-020 至 BUG-034 独立记录在[缺陷索引](../bug-records/README.md)：目录读写校验、并发偏好写入、当前表单保存、原生关闭确认、延迟取词、反馈接收端容量／异常／超时、辅助进程退出与编码、上传中断、桥接测试依赖、升级保留文件、日志故障后的桥接恢复、已删除模式被主页快照写回，以及反馈短屏越界。每条说明实际证据和未覆盖范围。

保留文件格式和已有用户数据；把校验放到数据入口，在失败时保留有效文件和草稿。保存临时文件采用同目录唯一名称并清理，避免并发冲突。接收端仍保留已文档化的限流和截断语义，不修改线上 nginx 或数据库。

## 负例与门禁

修改前源码保存在忽略目录 `before/`。目录／并发负例见 `catalog-negative-complete.log`，子页／关闭／延迟取词见 `ui-negative.log`，删除模式回写见 `deleted-mode-before.log`，反馈短屏见 `feedback-short-negative.log`，接收端见 `receiver-before.log` 与 `receiver-timeout-before.log`，插件见 `helper-before.log` 与 `upload-abort-before.log`，桥接见 `bridge-before.log` 与 `bridge-log-before.log`，安装脚本见 `installer-negative.log`。

旧的拒绝写入夹具通过占住固定 .new 文件名模拟失败；唯一临时文件修复后改为实际打开目标文件、拒绝替换权限，保留对回滚和原数据的严格检查。热键会话夹具先把编辑器滚入可视区，再记录用户可真实达到的焦点／选区／滚动状态，避免强行把焦点控件滚出视口造成伪失败。失败日志保留，不用无变化重跑代替定位。

新增目录／存储、插件、接收端、桥接及安装检查接入 Windows CI。全部 Python 测试使用唯一临时目录和随机回环端口；C# 使用隔离偏好；无真实反馈、模型请求或聊天发送。
