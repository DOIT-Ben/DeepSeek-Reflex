# v1.0.16 缺陷修复与验证

日期：2026-10-06。针对 BUG-001–BUG-011，保留发现时的 v1.0.14 源码快照；修复版本为 [v1.0.16](https://github.com/DOIT-Ben/DeepSeek-Reflex/tree/v1.0.16)。状态以[缺陷索引](../bug-records/README.md)为准。

## 测试隔离

Windows 11 x64 本机，单屏 2560×1600，200% 系统缩放。普通与 PerMonitorV2 manifest 的窗口夹具分别运行。全部偏好、日志、图片和 WebView 资料使用独立临时目录；未读取真实登录资料或私人对话。故障注入只终止独立环境返回的浏览器 PID，外部导航在初始化事件中被取消。

## 覆盖与结果

- 既有窗口检查：普通与高 DPI 各 274 项通过，覆盖偏好、热键、真实模态返回、四边四角拉伸、圆角层级、任务栏身份、托盘关闭、动画及 GDI 资源回归。最终完整运行没有 SKIP；前台权限不足的项目仍按既有规则明确 SKIP，不得据此宣布所有物理桌面操作全部通过。
- 新增 51 条核心与原生边界检查：设置／引导两种收起方式、最大化恢复、真实热键保存拒绝回滚、MSAA/UIA 状态、负坐标 DPI 消息、缓存不重复上传、短引导固定页脚、统一登录弹窗、真实浏览器进程退出重建与关闭中初始化取消，全部通过。
- 3 条剪贴板边界检查：内存适配器执行生产逻辑，成功与取消均恢复原内容，其他应用更新不覆盖。不是实体剪贴板或所有应用兼容性验收。
- 11 条草稿检查：运行生产生成脚本的模拟 DOM，个人草稿保护、同文不同编辑器、编辑后还原、SPA 路由、提交撤销所有权、替换时清理监听器、模糊编辑器和 contenteditable 草稿保护，全部通过。
- 10 条聚焦检查：运行生产生成脚本的模拟 DOM，不读取或写入草稿；普通、高 DPI 与边界入口均通过。
- 真实旧启动器检查：空参数、带空格路径、Unicode、引号与尾部反斜杠正确转发，不打开官网。
- 发行包：精确文件清单、全部 payload 哈希、EXE 与版本、6 张 README 图片以及随包链接存在性；历史包的缺失文档链接应被新检查拒绝。

图标打包检查还发现旧检查在 200% DPI 下对 ICO 与 EXE 提取出的重采样像素作比较，可能误报。已用 PE 数据资源读取逐个比较七种尺寸的原始帧字节，程序、兼容启动器与安装器均与源图标完全一致；透明度、主体比例检查仍保留。没有替换用户已认可的 Logo。

完整原生回归曾因桌面焦点／消息时序出现单次失败，保留失败日志并重跑相同断言，未降低检查要求。弹窗关闭中真实测试最初复现 E_ABORT，修复关闭标记后通过。测试编译期间的夹具成员拼写错误已修正，不计为程序缺陷。

## CI 与执行入口

```powershell
pwsh -NoProfile -File .\webview-host\tests\run-tests.ps1
pwsh -NoProfile -File .\webview-host\tests\run-boundary-tests.ps1 -CoreOnly
pwsh -NoProfile -File .\packaging\test-package.ps1 -ZipPath .\release\DeepSeek-Reflex-1.0.16-Windows-x64.zip
```

GitHub Actions 在打包检查后执行 CoreOnly 门禁；原生桌面、真实 WebView 和 UIA 检查不会在 CI 中冒充完成。公开 CI 链接在 BUG-009 档案中记录。

## 尚未覆盖

BUG-007 的代码、负坐标消息及合成缩放检查通过，实体混合 DPI 多屏仍待验收。需要两块缩放不同的显示器，往返拖动主窗、设置、引导与登录弹窗，检查文字、按钮、圆角、尺寸恢复和拉伸指针；单屏无法替代。

没有对真实官网账户执行故障注入或逐个第三方登录提供商测试；保留资料目录不等于保证服务端登录永不失效。没有逐机验收 Windows 10、所有 Word／浏览器取词与实体键盘；网站自身更新仍需要兼容性回归。macOS 当前不支持。

本轮未实现 ADR-0001 的贴边收纳或自定义指令，也未制作演示视频。签名申请已被 Foundation 拒绝，发行包仍明确未签名。
