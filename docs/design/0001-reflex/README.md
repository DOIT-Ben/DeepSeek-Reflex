# 贴边收纳与快捷指令 · 交互预览

这是基于 v1.0.12 的可点击设计稿，**尚未接入安装版**。[ADR-0001](../../adr/0001-edge-dock-and-custom-prompts.md) 保持 `PROPOSED`，对应输入已获[独立审查 PASS](../../adr/0001-review.md)。本轮阶段与原生接入要求见[测试合同](../../adr/0001-stage-tests.md)。

## 打开预览

下载仓库后，用浏览器打开同目录的 [index.html](index.html)。也可以从仓库根目录启动只监听本机的静态服务（需 Python 3）：

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory docs/design/0001-reflex
```

随后打开 `http://127.0.0.1:8000/index.html`。页面内嵌原有蓝鱼 Logo、样式和脚本，无构建步骤或外部依赖。

## 怎么试

1. 点“小窗设置”，打开“贴边收纳”并保存。拖动标题栏到演示桌面左侧或右侧，松手后只留蓝鱼标签；点击恢复，经过不会弹出。设置开关默认关闭。
2. 点右侧“演示取词”，使用演示材料查看固定两行的取词栏。打开“更多指令”→“管理快捷指令”，新建一条指令，或选“提炼要点、润色表达、解释报错”作为编辑起点。
3. 在同一设置面板里编辑、删除、返回或保存。未保存退出有“继续编辑／放弃”选择；普通设置与指令目录独立保存。
4. 点“放入一段用户草稿”，再取词或换指令。原草稿会保留，可查看“复制请求”；清空演示草稿后可以再次填入。请求需要你确认发送。
5. 展开“其他演示场景”，检查保存失败、四步引导或重置。失败会保留编辑内容，关闭失败开关后可重试。

浮层支持方向键、Home、End、Enter、Esc 和点击外部关闭。预览页内的 Ctrl+Space、Ctrl+Shift+D 只模拟唤起与取词；也可以聚焦标题栏，用方向键移动、Enter 尝试收纳。浏览器或系统可能先处理这些组合键，右侧按钮始终可用。

## 设计边界

| 部分 | 预览里的行为 | 后续原生接入 |
|---|---|---|
| 贴边收纳 | 演示桌面左右 12 DIP 内释放；标签约 32×80 DIP；点击恢复原尺寸、位置与草稿 | 独立控制器、外侧屏幕几何与独立透明标签，主 WebView 保持存活 |
| 快捷指令 | 三条内置指令、最多 20 条自定义指令、固定两行取词栏、同框管理页 | 独立版本配置与目录，复用官网草稿安全填入 |
| 设置与引导 | 共用一个 22 DIP 圆角外框，内容滚动，操作区固定，按钮／开关反馈一致 | 延续现有外框及模态入口，验证四角图层与任务栏行为 |
| 数据与发送 | 手写教学内容；只在内存修改；刷新或重置恢复默认；“发送”只添加演示消息 | 使用官网登录与聊天；请求填入后由用户确认发送 |

预览不访问官网，不读取系统选区、剪贴板、账户或原生配置，不保存材料及聊天内容。这里的“复制请求”展示已选中的纯文本，可手动复制；它没有调用剪贴板 API。浏览器中的 CSS 像素用于表示逻辑尺寸，较小的演示桌面会等比缩放。
