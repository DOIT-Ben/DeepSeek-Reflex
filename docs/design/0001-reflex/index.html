月亮的阴晴圆缺
怎样向学生解释月亮的阴晴圆缺？

月亮一直都在，变化的是我们看到的亮面。

月亮本身不发光，太阳照亮它的一半。月亮绕地球运动时，我们看见的亮面比例也会改变，于是出现新月、上弦月、满月等不同形状。

可以拿手电筒照着一个小球，换几个观察角度，让学生自己发现变化。
