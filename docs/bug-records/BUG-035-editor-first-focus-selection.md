# BUG-035：点击编辑时提示词被自动全选

- 优先级：P2
- 状态：已修复，本地普通／高 DPI 专项各 11 项通过。

## 现象

点击内置模式“编辑”后，提示词呈蓝底白字全选，直接键入容易替换整段内容。

## 复现

在聊天模式页首次编辑总结模式，然后切换翻译、再切回总结。修改前新增的选区断言失败，见忽略目录 `webview-host/tests/results/caret-before.log`。

## 代码证据

`webview-host/SettingsDialog.cs` 的 EditBuiltinMode、EditCustomMode、指令编辑与示例入口；`SettingsTests.cs` 的 TestAuditUi。

## 根因

加载文本后只调用 Focus，未覆盖原生文本框首次聚焦的选区行为。

## 修复方案

加载编辑内容后统一先聚焦，再显式设置末尾零长度选区。相同处理用于自定义模式、快捷指令和示例填入入口；不修改普通点击、拖选、Ctrl+A 或整组恢复时的选区语义。

## 验收标准与结果

修改前失败；修改后 `caret-after.log` 普通／高 DPI 各 11 项通过，检查首次与重复编辑的焦点、末尾光标、零长度选区、输入追加和主动全选。沿用隔离偏好，不发送全局测试按键。
