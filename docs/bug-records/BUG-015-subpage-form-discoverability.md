# BUG-015: 两个子页的表单没有标题、按钮语义靠悬停才可发现

- 状态：已修复关闭（2026-11-06，用户安装实拍反馈）
- 优先级：P2
- 影响面：设置的「快捷指令」「聊天模式」两个子页

## 现象

用户在安装 1.0.19 实拍「快捷指令」页后问"这个页面想表达什么？怎么操作？"。表单（名称/指令两个白字段）悬空无标题；「新增指令」实际行为是"填入示例模板"；「保存条目」与主按钮「保存指令」两级保存的区别只写在鼠标悬停 tooltip 里；页面不说明这些指令在哪里使用（取词栏指令菜单）。

## 复现

打开设置 → 快捷指令（或聊天模式）。不悬停任何控件的前提下，无法看出：表单是干什么的、两个保存按钮的先后关系、指令在哪里生效。

## 根因

操作语义全部依赖 `ToolTip`（SettingsDialog.BuildCommandsPage/BuildModesPage），页面静态文本只列了内容清单，没有承载"在哪用、怎么存"的说明；按钮命名与真实行为不符（新增指令=预填示例；保存条目=写入内存列表；保存指令=落盘）。

## 修复（实施记录 2026-11-06）

- 表单加标题：`BuildEditorCard` 增 `formTitle` 参数，两个子页分别标注「自定义指令（新增或编辑）」「新增自定义模式或修改内置提示词」。
- 命令页 intro 扩为两行：指令在哪里用（取词栏指令菜单）+ 内置不可修改；命令列表相应下移并收紧 12 DIP（AutoScroll 兜底）。
- 按钮按真实行为改名：两子页「新增指令/新增模式」→「填入示例」，「保存条目」→「保存到列表」（两页同名保持既有可见页选择器约定）；tooltip 同步为两级保存说明。
- 高度预算：CommandsContentHeight 332→338（对话框 476→482），ModesContentHeight 420 不变（编辑器下移 22 后按钮 382..412，尾距 8）。

## 验收证据

- 全量回归通过（default 419 + high-dpi 419 零 SKIP，含小视口滚动与页面适配检查）；测试钉点 `保存条目`→`保存到列表` 同步（SettingsTests.cs:395）。
- 用户安装版（install.ps1 重装）实拍复核。
