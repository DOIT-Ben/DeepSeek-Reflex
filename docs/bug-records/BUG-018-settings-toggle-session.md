# BUG-018：设置打开后全局唤出键失效，无法保留草稿收起窗口组

- 优先级：P2
- 状态：已修复关闭（2026-11-06，两套窗口回归通过，已更新本机安装）
- 影响：设置主页、快捷指令及聊天模式两个编辑子页；帮助、反馈与登录不扩展窗口交互。

## 复现与证据

修改前打开设置，实际热键注册被全部暂停，主窗的唤出分支又无条件拦截设置期间切换。隔离测试 `settings-session-before.log` 在 `settings keeps the real global toggle registered` 失败，源码快照保存在 `webview-host/tests/results/ui-20261106/white-session-before/`。

直接隐藏 `ShowDialog` 不能保留编辑会话：隔离实验约 222ms 后返回 Cancel，因此改成主窗拥有的非模态单实例窗口，通过关闭事件释放会话。

## 修复

- 热键可用范围显式区分 All／ToggleOnly／None；设置时仅保留唤出键，录入期间才全部暂停。
- 整组切换复用同一个设置对象，保留草稿、页面、滚动、文本选区；恢复在主窗激活消息后还原编辑焦点。
- 设置期间仅暂停竞争输入与配置操作，允许主窗移动与原生调整大小；取消、保存失败和冲突沿用恢复语义。
- 显示新快捷键不等于注册成功；成功写入并应用后才替换有效键，失败保留表单和原注册。

## 验收

以真实 RegisterHotKey + SendInput 路径覆盖两种收起方式、三个页面、重复切换、Esc／Tab、未保存键、写入失败、热键冲突、成功保存及退出。最终记录见 [验收报告](../testing/2026-11-06-white-settings-session.md)。
