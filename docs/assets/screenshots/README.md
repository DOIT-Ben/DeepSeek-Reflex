# Screenshot sources

These screenshots were captured afresh for v1.0.14 on Windows 11 at 200% display scaling. The native controls are built from the shipping source; the screenshot session uses a separate demo profile, a fresh signed-in conversation, and demonstration text. No existing screenshot, user chat history, or unreleased interaction prototype is used.

The website content is rendered by the official DeepSeek website inside WebView2. Website controls and text may change independently of this application. Images are direct screen captures, without compositing or replacing the website content.
