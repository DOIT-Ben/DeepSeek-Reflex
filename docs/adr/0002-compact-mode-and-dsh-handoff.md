# ADR-0002：紧凑模式入口与 DSH 一键带入

**PROPOSED · 2026-10-19**。代码基线 `7a5902dc279e6fa9166896a1a48ee005a082a760`，main，原生版本 1.0.17，插件 0.1.1。

来源、影响与阶段/测试合同分别见 [来源与影响](0002-impact.md)、[阶段合同](0002-stage-tests.md)。方案门禁和实施进度的唯一所有者是 [审查与实施记录](0002-review.md)。本 ADR 不修改 ADR-0001 的受检内容。

## 目标与边界

用户在下一轮功能建议后要求“开始按照ADR推进”。本轮落实建议中的前两项：模式入口不再额外占一行；DSH 草稿经明确点击后带入同一个官网小窗，供用户检查并发送。自定义模式、贴边收纳、官网回复自动读取、新建官网对话、自动发送、远程 DSH 和安装发布均不在本轮范围。

## D1：标题栏内的模式选择

保留现有 44 DIP 标题栏、左侧三按钮和右侧两按钮。把中间标题替换为有可访问名称的 ghost 模式按钮：普通模式显示“普通对话 ▾”，其他模式显示现有模式名称。应用名称由原生窗口 Text、任务栏、托盘保留。中间按钮与左右组有间隔，最小窗口和 100/150/200% 缩放下不重叠；菜单支持键盘及关闭后回焦。正常状态不显示重复说明行。

保存失败和注入异常仍可在模式按钮 tooltip/AccessibleDescription 中读取，并在菜单的禁用说明项中展示；下一次成功刷新清除过期错误。原六模式 ID、提示词、持久化与选词语义不变。旧测试中的独立栏断言须替换为实际可观察的标题栏和高度断言，不能删除模式覆盖。

备选：把入口移到官网 DOM 内会依赖页面结构；继续保留工具行则不能回收高度。本轮选择原生标题栏。

## D2：只在本机传递的窄协议

DSH host 新增同源 loopback POST `/reflex-window/stage`。只接受 JSON `{id, mode, text}`，id 为 UUID，mode 必须属于现有六模式，text 为 1–20000 个 UTF-16 单元，整个 UTF-8 请求不超过 90000 字节，读取期限 3 秒。保留旧 status/open 无请求体合同、来源和自定义头防护。每个 host 同时最多一个 launch/stage；不可用时返回固定错误码，不回显路径和正文。

host 只启动已定位的 DeepSeekFloat.exe，固定参数 `--reflex-bridge`，shell=false、隐藏辅助进程，用标准输入传 JSON，标准输出只允许有界协议结果；正文不出现在命令行或临时文件。host 最多等待 12 秒，超时终止自己创建的辅助进程，不重试、不改写剪贴板、不声称未填入。

原生辅助入口在 Program 主窗口/互斥创建之前处理：读取有界 JSON，连接本机命名管道，必要时只启动同目录同 EXE 的无参数主窗一次。管道名按当前 SID、登录会话 ID、规范 EXE 路径的摘要区分；ACL 只授予当前用户，拒绝网络 SID。客户端写正文前通过 GetNamedPipeServerProcessId 校验服务器 EXE 路径；服务器读正文前通过 GetNamedPipeClientProcessId 校验辅助进程 EXE 路径。路径不匹配、无权限或校验失败均 fail closed。管道只提供 stage，不提供脚本、URL、任意文件路径、退出或执行命令。

管道服务归属独立 `ReflexBridge`；协议校验/序列化和辅助入口不依赖 ChatWindow。主窗只负责 UI 线程的唤起、单次填入协调。禁止向 ChatWindow 堆入管道解析、进程鉴权或 HTTP 职责。管道请求/响应最长各 90000/2048 字节，读取和 UI 等待有界；Dispose 关闭等待中的管道。响应只含 id、status，status 为固定枚举。服务器不排队等待网页或模态就绪，不后台延迟重放。

备选：本机 HTTP 额外监听需要端口和鉴权生命周期；临时文件传正文违反不落盘边界；命令行传正文会暴露到进程清单。因此选固定辅助入口与 ACL 管道。相同 Windows 用户对自身可执行文件的修改不属于本协议能隔离的权限边界。

## D3：单次安全填入

主窗回调在 UI 线程捕获唤起目标；设置/引导打开时聚焦当前面板并返回 busy。复用 ShowChatAt，保留同一个 WebView。未初始化返回 loading；不等待官网登录或自动导航。使用 `ChatModes.Prefix` 组合原始文字，调用现有 `PromptInserter.InsertAsync`，previous=null，因此只有空编辑器可接受，任何个人或之前工具草稿均拒绝覆盖。

填入前已有持续模式注入器时，通过现有一次性请求所有权机制挂接本次完整请求；不修改 settings.ChatMode，不把要求切普通模式交给用户。输入器仍校验官网 HTTPS origin、唯一编辑器和最终内容；失败不自动点击发送/清空/重试。确认填入才返回 filled。同一时刻只处理一次；用户显式重试遇到已有文字时拒绝覆盖。响应丢失/超时返回 outcome-unknown，用户先检查小窗，不自动重放。网页结构不兼容时保留手动复制路径。

## D4：插件交互与兼容

保留原有菜单、六模式和回复预览。新增主动作“带入小窗”，旧动作改为次要“复制请求并打开”，作为用户显式选择的兼容路径；复制按钮继续说明需普通模式。自动路径直接传原始文字与 mode，不再重复组合提示词，也不读取剪贴板。仅成功 filled 后绑定触发时的 DSH 草稿快照。异步结束必须重新核对组件存活与会话；会话变化后不把结果或 pending 绑定到新会话。原会话文本修改保留，回填沿用 revision/附件/引用保护。

缺少新版小窗协议时显示手动复制指引，禁止自动降级写剪贴板。远程/file 页面仍拒绝。旧安装版保持可用；本轮仅开发构建，原生 VERSION/manifest 不变，不宣称旧安装版支持新协议。插件开发版本改为 0.2.0，运行文件白名单包含新增模块，构建无需引入运行依赖。

## D5：验证、阶段与回退

在干净主工作树本地实施。若源码修改前现场变脏且内容不属于本轮，依 adr-implementation 的工作树规则处理；隔离树只能在本仓库上一级同盘目录。本地构建/隔离测试获准，提交推送、发布和安装替换不在本轮授权中。

S0：方案独立审查，最多两轮，PASS 指纹核对后记录可实施。S1：紧凑入口、原生回归与独立实现审查。S2：传递协议、插件交互、安全回归、隔离 WebView 与 HTTP/管道测试、独立实现审查。S1/S2 各最多两次修复、三次结论。完成谓词见阶段合同，记录只在审查与实施记录维护。

本轮隔离 WebView 使用官方 origin 下拦截的自有 HTML，验证编辑器与不发送行为，不访问用户聊天。浏览器 fixture 验证插件用户操作，启动器/剪贴板为替身；独立传输测试覆盖真实子进程与管道。官网登录后的真实往返、个人 DSH profile 集成与物理多屏仍单列待验收，不由 fixture 冒充。出现无法安全复现的环境问题保留断言并记录。

回退：禁用/移除插件恢复原 DSH 输入；旧“复制请求并打开”继续使用旧小窗。原生关闭管道服务不影响普通聊天；撤回本轮源码即可恢复旧模式栏，持久模式设置版本和已有数据不变。
