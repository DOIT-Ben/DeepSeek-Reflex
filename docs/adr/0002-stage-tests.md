## 原生

- N01：360 DIP 最小宽度、小窗、阅读宽度，100/150/200% 下模式按钮与两侧控制不重叠，浏览区紧接 44 DIP chrome，回收旧 38 DIP；有选词栏时其布局和关闭行为正确；六模式菜单与失败反馈可达；截图为测试窗口。
- N02：隔离 WebView 官方 origin 下自有 fixture，空编辑器成功填入，text/mode 一致，不读写个人官网；真实管道与固定辅助进程 stdin/stdout 有界往返另行验证。
- N03：持久翻译模式下带入润色请求，精确只含润色前缀一次；持久设置仍为翻译；请求发送后的新输入恢复翻译；不会自动触发 fixture send。
- N04：非空草稿（包括此前工具填入）、错误 origin、多编辑器、初始化未完成、模态、并发、无响应时不覆盖/不发送；错误固定且可识别；超时只报告未知，不重放。
- N05：离线原生构建、既有模式/草稿/聚焦/唤起相关回归；保留原实体多屏和环境限制，不能降低断言。仅使用临时偏好/测试页面，不修改个人安装。

## 协议与宿主

- T01：POST stage 仅传 `{id,mode,text}`，固定 EXE、固定参数、shell=false、stdin 写 JSON，无文本 argv/临时文件/剪贴板/API；旧 status/open 仍拒绝正文。stdout 长度/JSON/id/status 校验；进程超时仅清理自己创建的 helper。
- T02：跨源/远端/缺头拒绝；错误 method/content-type/未知字段/非法 ID/模式/空文/超长/超字节/慢 body 拒绝；单任务门禁；pipe ACL/网络拒绝、双方 EXE 身份验证与退出释放；损坏消息不使服务永久退出；本机 transport smoke。

## 插件浏览器

- P01：真实 React fixture 操作新主按钮，发一次 stage，正文为原始草稿，mode 正确；不写剪贴板、不更改 DSH 草稿；filled 才绑定；模态/草稿/初始化错误和未知结果明确；会话切换/卸载/快速双击无错误绑定或重复调用。
- P02：旧六模式复制、预览、确认回填与附件/引用/版本保护回归；新旧草稿 API，窄视口/顶层 popover/键盘退出回焦仍通过。

真实 DSH+官网登录往返不是隔离测试可以证明的结论，交付必须明确列为待验收；不得把本地 S1/S2 通过表述为已发布或个人环境已升级。
