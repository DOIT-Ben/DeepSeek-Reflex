## P：设计稿行为与视觉验收

| 编号 | 场景／环境 | 预期可观察结果 |
|---|---|---|
| P01 | 初始、设置取消／保存 | 贴边默认关闭；开关编辑后取消不应用，保存后生效 |
| P02 | 拖标题至左右边缘，分别开启／关闭 | 开启且移动释放到 12 DIP 内时只显示一枚标签；关闭不收纳；拖动前有正常矩形 |
| P03 | 收纳、hover、点击，重复左右操作 | hover 不展开；点击恢复原尺寸与位置；演示草稿保留；标签不成为正常尺寸 |
| P04 | 收纳后模拟唤起、托盘打开、取词 | 统一恢复；取词模拟保留演示材料；面板操作先恢复 |
| P05 | 最小化、关闭、两种快捷收起方式、设置／引导 | 任务栏恢复及托盘入口可用；收起行为遵从设置；模态期间不收纳，关闭后四角轮廓完整 |
| P06 | 取词前／后、410 DIP 和最小可视宽度 | 取词前无指令入口；显示后固定两行，状态与按钮不重叠 |
| P07 | 更多列表的点击、上下／Home／End／Enter、Esc | 选择正确指令并关闭；Esc 返回触发器焦点；关闭后没有残留浮层 |
| P08 | 点击浮层外、空目录、多条／长名称 | 正常退出；空态有管理入口；内容可滚动且不越界 |
| P09 | 同一设置框新增、编辑、示例、取消 | 示例只成为编辑稿；取消不修改目录；保存的内容可从更多指令选用 |
| P10 | 删除后放弃及确认保存、未保存时返回／关闭 | 放弃恢复原目录；保存才删除；未保存退出有明确可撤销选择 |
| P11 | 空名称／正文、重复、超长字段、超过 20 条 | 校验贴近字段，已有编辑内容不丢失，保存未生效 |
| P12 | 演示保存失败开关、普通设置与指令独立保存、刷新 | 失败留稿可重试；保存指令不应用普通设置；刷新恢复全部演示默认，未使用本地持久存储 |
| P13 | 输入框已有用户草稿后取词／换指令／填入 | 草稿逐字符保留，出现可复制替代入口，无自动发送 |
| P14 | 清空草稿后重试、工具草稿再修改／再换指令 | 工具拥有的未修改草稿可替换；用户修改后保留 |
| P15 | 请求预览、材料含引号／HTML／伪指令 | 演示材料以纯文本包裹；复制预览不触发脚本、外部请求或自动发送 |
| P16 | 浏览器 1280×800、1440×900；DPR 1／1.5／2；较窄视口；减少动态效果 | 蓝鱼、22 DIP 主框、统一按钮与焦点；四角完整；弹窗内容可滚动，底部操作可见；动效可减弱 |
| P17 | 离线打开、重置、浏览器网络与控制台 | 自包含并标注交互预览；无外部资源、账号／Cookie／storage 读取或任务引入的控制台错误 |

不同 DPR 的浏览器截图只证明 HTML 渲染，不证明 Windows 原生 DPI 切换。P02 只能证明演示桌面的左右收纳；多显示器接缝由 N01 的原生几何输入验证。

## 恢复与证据归属

设计阶段新文件和 README 可按精确清单撤回，原生文件及用户资料不在修改范围。N 阶段实施前保全受影响配置与程序，并按项目发行流程保留恢复路径。

测试日志、截图和浏览器完整输出保存在仓库外的任务目录；仓库验收说明只引用实际执行的摘要，不收录用户聊天、账号、邮件或运行凭据。
