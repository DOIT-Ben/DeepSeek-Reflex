## P01：安装目标与文件保全

用真实 NSIS 指令段在隔离目录执行；屏蔽外部注册表与真实 EXE 注册调用，不能把所有文件操作替换为返回成功的空函数。

- 空旧目录作为当前安装目录、旧目录的子目录作为当前安装目录：新 EXE 和安装文件均存在，退出码为 0。
- 新默认目录安装，旧目录含额外哨兵文件（及未占用的旧 Float EXE、不含旧启动器以独立于 I2）：全部旧文件保留，新文件完整。
- 对新建临时目录验证绝对路径边界；fixture 不访问真实 LOCALAPPDATA、开始菜单、桌面、启动项、注册表或个人安装。
- 基线中的递归删除必须让至少一个保全断言失败，证明回归可发现 #1；修复后通过。

## P02：占用成功/失败分支

- 旧启动器存在未占用、两种旧 EXE 都存在未占用、无旧文件：成功退出且写入新载荷。
- 分别独占写访问锁定当前新 EXE、旧 Float EXE、旧启动器：原占用分支非零退出，载荷不被覆盖。
- 成功分支不落入 `install_busy`；对旧启动器的未修复基线必须发现失败。
- I2 后重跑 P01，不依赖删除旧文件取得成功。

## N03：实际文字渲染

- 真菜单组件/renderer、实际系统字体，100/150/200% 参数；内置六模式的完整文字渲染与无省略参考一致，勾选列不侵占文字。
- 同字体、同可用矩形对照，能发现绘制漏 NoPadding 的基线；不能仅断言复制出的宽度公式。
- `&` 字面名称的量测和绘制一致，超长文本仍有界省略。
- 编译当前生产源码通过，测试仅在临时目录落盘。

## N04：页面切换与工作区

- 对有限工作区进行高度拟合后，常规→快捷指令→返回常规；检查窗口和保存/取消屏幕矩形仍位于工作区，正文不足时可滚动。
- 真窗口导航用仅影响测试窗口的 DPI 参数制造有限空间，不改 Windows 显示设置；合成工作区的 FitBounds 数学用例覆盖100/150/200%。
- 构造直接打开指令页、指令保存返回、普通保存/取消、原快捷键录入与锚点行为不回归。
- 未修复高度恢复基线至少一个边界断言失败，修复后通过；当前显示器组合与合成几何的证据分别记录。

## N05：联系方式生命周期

- 非空成功→重新打开正确回填→清空成功→重新打开仍为空；当前匿名 JSON 不包含 contact。
- 非空/空反馈失败：原已记住的值不被改写。
- await 期间编辑 contact：成功后保存提交快照，不能保存未发送的新值；mock 不发网络请求。
- 偏好写失败不重发、不把已成功的反馈误报失败，关闭窗口后的既有保护仍保留。
- 原非空条件基线必须在清空用例失败；实现后通过。

## N06：收尾回归与边界

- 离线原生编译、N03–N05 和相关既有 SettingsTests 在隔离 Preferences 初始化下通过。保持原断言；环境焦点跳过/历史失败单独报告。
- 存储初始化不得执行个人目录迁移；反馈无真实请求，不启动个人 DSH 或官网对话。
- 文档链接、git diff --check、工作树归属及测试进程退出核验。无提交/推送/发布，不用本地结果冒充已发布或 Issue 已关闭。
