# 持续对话模式

2026-10-12 完成开发，v1.0.17 起提供。

v1.0.19 的模式选择位于标题栏，默认普通对话。选择模式会给当前草稿和后续消息自动添加可见提示词，发送仍由用户完成。

| 模式 | 行为 |
| --- | --- |
| 普通对话 | 不添加任务提示词；每条消息开头附一行模式声明，使此前消息中的模式指令过期（ADR-0005） |
| 翻译模式 | 中文译为英文，其他语言译为中文，仅输出译文 |
| 解释模式 | 通俗中文解释含义、难点，必要时举例 |
| 理解提问 | 理解内容并提出值得追问的方向 |
| 润色模式 | 保持原语言与事实，改善表达 |
| 总结模式 | 提炼主要观点与关键信息 |

模式选择保存为原 `window-settings.json` 的可选 `ChatMode` 字段，配置版本保持 1；旧设置或未知模式使用普通对话，其他设置保留。写入失败时保留原模式并提示重试。材料和聊天内容不保存到模式配置。

`ChatModes.cs` 集中维护稳定 ID、显示名称和固定提示词，菜单与注入脚本从同一目录生成。添加内置模式只需新增目录条目，不能把 ID 与数组序号绑定。

2026-11-05 起支持自定义：设置对话框新增「聊天模式」页（入口：设置主页动作行，或模式菜单底部「自定义提示词…」）。内置五种带提示词模式的指令可编辑、可逐个恢复出厂文案，覆盖与取词栏措辞保持一字不差；「普通对话」保持不加任务提示词的语义不可编辑（其消息头部的模式声明由运行时固定生成，ADR-0005）。可新增自定义模式（名称≤16 字、提示词≤2000 字、上限 10 个），出现在模式菜单；删除正使用的自定义模式后当前模式回退普通对话并重注入。自定义内容存于本机 `modes.json`，坏文件只加载内置并保留原文件，合同与 `commands.json` 一致。DSH 插件菜单仍只列内置六模式；内置被覆盖时经宿主组合自动生效。目标语言选择仍留待后续需求。

同日起（ADR-0005），每条经模式链发出的消息首部带一行当前模式声明：普通对话声明"无任务指令、按普通对话直接回答"，任务模式声明"以下指令为本条消息的任务"；两种形态都声明此前消息中的模式指令已过期、上文材料内容仍可引用。用途是压制旧模式指令在服务器侧会话历史里的延续（切换模式后新消息不再带旧腔调）。声明头由宿主运行时生成，不可自定义、不占 `modes.json`；在输入框中原样可见，随用户确认后发送。一次性取词请求同样带头（按其动作对应的模式）；自定义取词快捷指令不带。

`ChatModeInjector.cs` 仅在 HTTPS `chat.deepseek.com` 顶层页面运行。识别官网 `#chat-input` 或带“发送消息”占位文字的 textarea，要求唯一、可见、可写；不操作历史编辑框、其他来源、子框架或暂不支持的富文本编辑器。网站重载后从宿主恢复当前模式，SPA 替换输入框后沿用现有监听。

提示词在输入时可见，而非隐藏改写请求。工具只替换自己记录的前缀，保持原文与 textarea 选区；空材料不会产生一条只有提示词的草稿。中文组词期间暂缓处理。用户修改提示词后保留修改，不重复添加；清空输入框后恢复所选模式。取词填入暂停持续注入，并标记为一次性请求，保留已有的草稿保护和发送确认行为。“复制请求”记录本次工具复制的完整文本，粘贴该请求到当前页面时同样跳过重复注入；复制回执只存在页面内存中。

验证使用隔离偏好、自有窗口及本地响应拦截的真实 WebView，未操作个人官网登录资料或发送真实模型请求。Core 检查、模拟 DOM 检查与真实 WebView 行为是不同证据层，具体见 [回归说明](../webview-host/tests/README.md)。官网更换编辑器结构时仍需实测适配。

本轮实际结果及完整回归的环境限制见 [2026-10-12 验证记录](testing/2026-10-12-chat-modes.md)。
