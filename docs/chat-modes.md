# 持续对话模式

2026-10-12 完成开发，v1.0.17 起提供。

标题栏下的模式栏始终可见，默认普通对话。选择模式会给当前草稿和后续消息自动添加可见提示词，发送仍由用户完成。

| 模式 | 行为 |
| --- | --- |
| 普通对话 | 原文输入，不添加提示词 |
| 翻译模式 | 中文译为英文，其他语言译为中文，仅输出译文 |
| 解释模式 | 通俗中文解释含义、难点，必要时举例 |
| 理解提问 | 理解内容并提出值得追问的方向 |
| 润色模式 | 保持原语言与事实，改善表达 |
| 总结模式 | 提炼主要观点与关键信息 |

模式选择保存为原 `window-settings.json` 的可选 `ChatMode` 字段，配置版本保持 1；旧设置或未知模式使用普通对话，其他设置保留。写入失败时保留原模式并提示重试。材料和聊天内容不保存到模式配置。

`ChatModes.cs` 集中维护稳定 ID、显示名称和固定提示词，菜单与注入脚本从同一目录生成。添加内置模式只需新增目录条目，不能把 ID 与数组序号绑定。自定义编辑、目标语言选择及其他模式管理留待后续需求。

`ChatModeInjector.cs` 仅在 HTTPS `chat.deepseek.com` 顶层页面运行。识别官网 `#chat-input` 或带“发送消息”占位文字的 textarea，要求唯一、可见、可写；不操作历史编辑框、其他来源、子框架或暂不支持的富文本编辑器。网站重载后从宿主恢复当前模式，SPA 替换输入框后沿用现有监听。

提示词在输入时可见，而非隐藏改写请求。工具只替换自己记录的前缀，保持原文与 textarea 选区；空材料不会产生一条只有提示词的草稿。中文组词期间暂缓处理。用户修改提示词后保留修改，不重复添加；清空输入框后恢复所选模式。取词填入暂停持续注入，并标记为一次性请求，保留已有的草稿保护和发送确认行为。“复制请求”记录本次工具复制的完整文本，粘贴该请求到当前页面时同样跳过重复注入；复制回执只存在页面内存中。

验证使用隔离偏好、自有窗口及本地响应拦截的真实 WebView，未操作个人官网登录资料或发送真实模型请求。Core 检查、模拟 DOM 检查与真实 WebView 行为是不同证据层，具体见 [回归说明](../webview-host/tests/README.md)。官网更换编辑器结构时仍需实测适配。

本轮实际结果及完整回归的环境限制见 [2026-10-12 验证记录](testing/2026-10-12-chat-modes.md)。

上述为发现时快照；发布前已修复初始化兼容性并完成全量回归，当前门禁见 [v1.0.17 发布验证](testing/1.0.17-release.md)。
