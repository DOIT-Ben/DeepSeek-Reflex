# DeepSeek-Reflex 标识

1.0.1 采用用户确认的蓝鱼与小窗造型：鱼头朝左、身体饱满、尾柄细且上弯，中央小窗表达“随时打开独立问答窗口”。上身、腹部和鱼鳍统一蓝色，保留白色分隔线、窗口和小眼点。没有直接采用 DeepSeek 官方 Logo 文件或字标；已经发布的 1.0.0 历史安装包不会被覆盖。

高清 PNG：[`assets/logo.png`](assets/logo.png)，原始尺寸 1254×1254，白色背景。2026-10-04 通过 Codex 内置 image_gen 对用户选定的饱满蓝鱼造型进行统一蓝色编辑，没有本地修改造型、调色或拼版。该 PNG 是当前发行标识的唯一图形源，各尺寸 ICO 从它导出。

应用 ICO 由该 PNG 做格式导出，包含 16、24、32、48、64、128、256 像素版本：

```powershell
pwsh -NoProfile -File .\tools\export-icon.ps1
```

构建将同一 ICO 嵌入程序并附带于发行目录；主窗口与托盘加载该文件，任务栏使用窗口图标，安装器、卸载器与快捷方式引用同一来源。
