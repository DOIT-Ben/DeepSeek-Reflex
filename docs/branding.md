# DeepSeek-Reflex 标识

蓝鱼与小窗的组合表达“随时打开问答窗口”。鱼头朝左，身体饱满，尾柄上弯；身体、腹部和鱼鳍统一蓝色，保留白色窗口与内部线条。图形由 AI 辅助制作，没有直接使用 DeepSeek 官方 Logo 文件或字标。

## 图标素材

[`assets/logo.png`](assets/logo.png) 是当前标识的唯一图形源，尺寸为 1254×1254，外部背景透明。应用 ICO 从它导出，包含 16、24、32、48、64、128、256 像素图层：

```powershell
pwsh -NoProfile -File .\tools\export-icon.ps1
```

导出按 Alpha 轮廓裁剪，保留原比例和约 2% 边距。构建检查透明四角、图形比例与各尺寸图层，避免托盘图标带白底或过小。

程序、主窗口、托盘、任务栏、安装器、卸载器与快捷方式使用同一 ICO。主窗口和托盘分别加载系统要求的大、小尺寸图层。

## 任务栏与升级

原生宿主和快捷方式共用固定的 `DOITBen.DeepSeekReflex.Windows` AppUserModelID，升级时继续复用。安装脚本与安装器创建 `DeepSeek-Reflex.lnk`；旧 `DeepSeek.exe` 保留为使用同一图标的兼容启动入口。

本机安装脚本只迁移明确指向本程序的旧快捷方式，并在更新目录中保留回滚副本。图标与链接更新后发送定向 Shell 通知，不清空全局图标缓存或重启资源管理器。图标资源、快捷方式关联和任务栏实际显示需要分别验证。
