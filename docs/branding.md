# DeepSeek-Reflex 标识

1.0.1 采用用户确认的蓝鱼与小窗造型：鱼头朝左、身体饱满、尾柄细且上弯，中央小窗表达“随时打开独立问答窗口”。上身、腹部和鱼鳍统一蓝色，保留白色分隔线、窗口和小眼点。没有直接采用 DeepSeek 官方 Logo 文件或字标；已经发布的 1.0.0 历史安装包不会被覆盖。

高清 PNG：[`assets/logo.png`](assets/logo.png)，交付尺寸 1254×1254，带真实透明 Alpha 背景。1.0.4 通过 Codex 内置 image_gen 去除外部白底，保留蓝鱼造型、白色小窗和内部线条。该 PNG 是当前发行标识的唯一图形源，各尺寸 ICO 从它导出。

应用 ICO 由该 PNG 做格式导出，包含 16、24、32、48、64、128、256 像素版本：

```powershell
pwsh -NoProfile -File .\tools\export-icon.ps1
```

导出时按 Alpha 轮廓计算图形边界、保留原比例并使用约 2% 边距，避免原图上下留白挤小托盘图案。验证逐层检查透明四角、图形占用和鱼的比例；白底或过小图标会使构建失败。

构建将同一 ICO 嵌入程序并附带于发行目录；主窗口与托盘分别加载系统要求的大、小尺寸图层，任务栏使用窗口图标，安装器、卸载器与快捷方式引用同一来源。本机更新脚本对程序图标与受管快捷方式发送 Shell 更新通知，不全局清空缓存或重启资源管理器。

1.0.5 为进程与受管快捷方式设置一致的 `DOITBen.DeepSeekReflex` AppUserModelID，明确任务栏归属。快捷方式注册只允许修改指向当前程序的链接，并保留参数与图标路径。窗口图标资源正确并不等于 Explorer 显示的任务栏按钮已经正确，验收需分别检查资源、关联和实际显示。

1.0.6 覆盖早期安装留下的 `DeepSeek.exe` 0.1.0：它原来仍带圆环图标，不在此前更新文件清单中。现在该文件是带相同蓝鱼图标的兼容启动入口，转发到 `DeepSeekFloat.exe`；两者一起构建、校验、备份和更新。调用旧入口保留当前单实例和用户设置。兼容入口图标正确仍需与实际任务栏固定项的显示分别验收。

当前原生宿主与快捷方式统一使用固定的 `DOITBen.DeepSeekReflex.Windows` 标识，与之前的 Shell 分组区分。后续升级复用此标识，不按版本生成新标识。本机安装脚本与发行安装器均创建完整品牌的 `DeepSeek-Reflex.lnk`；本机脚本只迁移明确指向本程序的旧 `DeepSeek.lnk`，原链接保存在该次更新的 `rollback` 目录。新的标识和链接用于隔离旧关联，不能凭文件读回结果宣称 Windows 任务栏的实际显示已修复。
