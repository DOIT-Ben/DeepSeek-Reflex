## 唯一来源

- 原生样式参数与字体工厂：[`PanelTheme`](../webview-host/SettingsPanelControls.cs)。所有原生字体通过 `TextFont` 创建；按钮、选择器、开关沿用现有共享组件。
- 插件构建器：[`scripts/build.mjs`](../plugins/dsh-reflex/scripts/build.mjs)，读取同一份字体、颜色、圆角、尺寸和动效参数，编入 CSS 变量。缺失参数或浏览器产物过期时 `npm run check` 报错。
- 浏览器控件配方：[`src/styles.js`](../plugins/dsh-reflex/src/styles.js)，统一按钮、输入框、弹层、焦点和禁用态。DSH 的表面与正文主题变量优先，保证深色宿主仍可读。

修改 `PanelTheme` 后，在插件目录运行 `npm run build` 和 `npm run check`；不要直接修改生成的 `client.js`。原生控件和 React 控件分别渲染，共享设计参数，无需新增运行时服务或配置。

## 字体与尺寸

使用系统已有的 Microsoft YaHei UI；浏览器后备为 Segoe UI、system-ui、sans-serif，不下载字体。以下为 100% 缩放的逻辑尺寸，原生按屏幕 DPI 缩放。

| 角色 | 原生 pt | 浏览器 CSS px | 用途 |
| --- | --- | --- | --- |
| 辅助 | 9 | 12 | 提示、进度、状态说明 |
| 正文 | 10.5 | 14 | 按钮、菜单、输入、字段标签 |
| 小标题 | 12 | 16 | 插件面板标题、引导品牌与快捷键信息 |
| 页面标题 | 15 | 20 | 设置及引导主标题 |

常规按钮高 32，输入框高 40，菜单行高 30；控件圆角 4，内容面板圆角 8。标题栏图标及取词栏保留其紧凑尺寸，窗口外轮廓圆角 12 DIP。

用户要求设置页字体再小两号后，设置采用同一主题的 `CompactFont` 变体：以上字号统一减少 1.5 pt，即 2 CSS px。设置正文 12、说明 10、标题 18；紧凑按钮高 30、按键框高 34。窗口由 440×644 缩至 380×536 DIP，并同步压缩标题、分组与左右留白。使用帮助同批改用 `CompactFont` 并收紧纵向节奏：内容高度收敛到 264 DIP，默认 400×452 窗口不再出现滚动条，短屏仍可滚动，底排按钮改用紧凑高度 30。其余界面沿用表内字号。

主文字 `#2a313f`、辅助 `#677082`、强调 `#4366ee`。白底对比分别为 13.05、4.98、4.80；正文达到 4.5。填充式基座下浅色卡底 `#ffffff`、输入底同卡白、字段下划线 `#cccccc`（`InputBorder` 仅作插件共享 token，宿主不再绘制）。

**状态坡道（2026-11-05 二次整改，替代旧淡蓝选中态）**：用户裁定旧的淡蓝 Tint 选中底 + 强调色文字"丑"，全部重置为 Fluent 式中性灰阶——rest → hover → 选中单调加深一档，无色彩染色；强调色只保留给主按钮、输入聚焦下划线、StatusDot 蓝点和链接。浅色：rest 白 → hover `#ececec` → 选中 `#e5e5e5`；深色：rest `#292929` → hover `#303030` → 选中 `#3a3a3a`。选中之上的 hover 只做 40% 混合微步，文字一律 Ink，不再随选中变蓝。

**底色种类收敛（2026-11-05 三次整改）**：用户裁定一个页面不许同时铺多种底色。浅色全应用只剩 4 种面：页底 Mica `#f3f3f3`、卡片白、交互灰 `#ececec`（悬浮=次级按钮共用同一种灰）、选中灰 `#e5e5e5`；按压态 `#d8d8d8`、开关轨道 `#c7c7c7` 只在瞬时出现。全部 R=G=B 纯中性灰，旧蓝偏色（淡蓝选中、蓝灰输入井、淡蓝按压闪、蓝灰开关轨道、蓝灰插件边框）全部清零；整个应用唯一彩色=强调蓝。深色同构：页 32 / 卡 41 / 交互 48 / 选中 58。

## 交互

- 同类按钮共用悬停、按下、释放与焦点规则；悬停 120 ms、按下 60 ms、释放 90 ms。原生遵从 Windows 动画偏好，插件遵从 `prefers-reduced-motion`。
- 宿主输入字段聚焦时，字段底部的下划线变为 2px 强调色（无整圈边界）；插件侧输入保留聚焦边界。禁用态保留可读文字。
- 插件入口展开后呈选中态；Esc 关闭并返回入口，空格可重新打开。
- 带入阶段强调“带入小窗”；回复可回填时强调“确认填回输入框”，只保留一个可用的主动作。草稿保护、确认回填和不自动发送的行为保持原样。
- 长标题在标题自身换行，关闭按钮固定；动作行允许换行，面板超高时内部滚动。

## 填充式基座（2026-11-05 起，同日两轮演进）

用户反馈设置界面"线框太多、嵌套丑、悬浮效果差、铺不满"后确立的原则，全应用统一；同日随后按用户"做得更原生"要求整体对齐 Windows 11 设置观感：

- **几何（Win11 标准）**：控件圆角 4 DIP、面板/卡片圆角 8 DIP、窗口圆角 12 DIP（原 22，贴近系统 ~8px 视觉）。
- **页面即 Mica**：浅色页底 `Back=#f3f3f3`（Win11 浅 Mica 近似），卡片白 `Card=#ffffff` 浮起；深色页 32 / 卡 41。
- **按钮三型**：主按钮 Accent 实底；次级按钮（返回/取消/继续编辑等）用交互灰 `Secondary=#ececec`（深 48）；Ghost/Segment 文字动作透明贴页底，无任何静止底色。
- **默认无线框**：全部控件不画静止描边；层次靠底色（页底 243 → 白卡 → hover/选中灰阶）。
- **文本框（2026-11-05 四次整改，Win11 原生字段）**：输入框不是灰块。字段=白色面直接贴灰页（或白卡），底部一条安静的下划线 `FieldLine=#cccccc`；聚焦时下划线变强调蓝 2px；字段面本身不做 hover/按压变色。模式/指令编辑器不再包白卡（编辑区直接在灰页上，字段自带白面）。
- **状态坡道（中性，替代旧淡蓝选中态）**：rest → hover `#ececec` → 选中 `#e5e5e5`（深色 48 → 58）单调加深、无色彩染色；选中文字一律 Ink，不再变蓝。强调色只留给主按钮、聚焦下划线、StatusDot、链接。
- **`Outline` 属性已删除**；**铺满**：编辑字段右缘按容器对齐；列表行与动作行按容器宽铺满。
- **输入单一表面（BUG-014 延续）**：`InputFrame` 填充尊重调用方 `BackColor`（现一律 `Card`），与内嵌无边框文本框同色合成一块；卡内/页内标签一律 `Color.Transparent`。
- **动作按钮不拉伸（BUG-014）**：子页布局只拉伸右锚定的行；「新增/保存条目/恢复默认/编辑/删除」保持并列固定宽度，不得铺成整行灰条。
- `InputBorder` 颜色仅作为 DSH 插件共享 token 保留（已中性化为 146 灰）。改动 PanelTheme 色值/几何后在插件目录跑 `npm run build` + `npm run check` 同步产物。
- 已知限制：聊天模式列表在自定义模式较多超出可视区时会出现系统滚动条（WinForms AutoScroll 不随应用主题着色，深色下为亮灰）；默认视图（普通+五内置+空态）经 196 DIP 列表高度与 24/28 行距已确保不触发。
- 卡片内的标签一律 `Color.Transparent`，避免页面色块浮在卡面上；空错误槽同理透明。

### 2026-11-06 子页字段与动作整理

用户确认主页融合式输入后，将同一规则扩展到全部自有页面：普通输入的文本、内边距及外壳统一直接父表面的颜色，静止轻底线、聚焦蓝底线；帮助页不用独立白卡，分段默认融入父面。原生菜单保留单一浮层边界；插件输入去除整圈边框并使用透明底，展开入口采用中性选中态。此前段落中白色 Card 输入配方由此取代。逐页清单与验证边界见 [自有页面协调验收](testing/2026-11-06-shared-surfaces.md)。

设置主页按快捷键、窗口行为、外观、内容与模式四组组织：组间留 16 DIP，组标题与首行留 26–28 DIP；快捷键及外观字段共用 124 DIP 标签列，内容左对齐。选择器采用 `Flat` 变体融入页面，仅选中项显示灰底；其它使用方保留原组件样式。内容管理保留两个独立入口，刷新／导入／帮助／反馈移到独立辅助行。主页内容高 520 DIP，工作区不足时滚动正文，保存与取消固定。

主页两个快捷键字段的外壳及文本框与所在分组同色，避免右侧两块白面切割页面；静止保留轻底线，聚焦使用蓝色底线。此配方只用于快捷键字段，模式／指令／反馈正文编辑面保持各自用途。

主页专项：`run-tests.ps1 -GeneralOnly`，普通／高 DPI 编译各 70 项通过，检查浅／深两主题、三种 DPI 几何、窄屏滚动、快捷键重置、管理页往返及主题／尺寸／收起方式的保存结果。`-EditorOnly` 兼容回归各 158 项通过。截图及日志在 `webview-host/tests/results/ui-20261106/general-final/` 和 `general-editor-regression/`，属于本地隔离验证，未替换个人安装。150% 的浅／深主题窗口截图已查看，其它 DPI 组合只报告几何验证。

模式和快捷指令共用纵向表单：标题、字段标签、完整输入面、就近错误、操作行。标签放在字段上方，禁止与输入面处于同一行后再按整行拉伸；否则透明标签也会遮住兄弟窗口，不能靠换底色解决。名称字段高 34 DIP，提示词高 88 DIP，输入和内边距共用 Card，无额外包裹卡片。

`InputPanel` 只绘制一块圆角表面和底部状态线；内嵌文本框保持无边框并缩进到圆角以内。设置中的快捷键和反馈字段继续共用此绘制方式。Ghost 动作在禁用时也融入页底，不出现另一块浅灰底。

表单动作由独立行容器统一排布，三按钮共用基线，窄窗口按行宽缩小按钮。「保存到列表」使用次级按钮，最终「保存模式／保存指令」保留唯一蓝色主按钮。子页错误提示保留独立空间；短工作区滚动正文，底部保存／返回固定可达。
