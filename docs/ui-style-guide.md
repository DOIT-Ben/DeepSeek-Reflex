# Reflex 共享界面样式

2026-10-23。本次收敛小窗标题栏、取词栏、设置、使用帮助、划词浮窗、托盘菜单、登录弹窗和 DSH 插件的自有控件。官网聊天正文继续使用官网排版。

## 唯一来源

- 原生样式参数与字体工厂：[`PanelTheme`](../webview-host/SettingsPanelControls.cs)。所有原生字体通过 `TextFont` 创建；按钮、选择器、开关沿用现有共享组件。
- 插件构建器：[`scripts/build.mjs`](../plugins/dsh-reflex/scripts/build.mjs)，读取同一份字体、颜色、圆角、尺寸和动效参数，编入 CSS 变量。缺失参数或浏览器产物过期时 `npm run check` 报错。
- 浏览器控件配方：[`src/styles.js`](../plugins/dsh-reflex/src/styles.js)，统一按钮、输入框、弹层、焦点和禁用态。DSH 的表面与正文主题变量优先，保证深色宿主仍可读。

修改 `PanelTheme` 后，在插件目录运行 `npm run build` 和 `npm run check`；不要直接修改生成的 `client.js`。原生控件和 React 控件分别渲染，共享设计参数，无需新增运行时服务或配置。

## 字体与尺寸

使用系统已有的 Microsoft YaHei UI；浏览器后备为 Segoe UI、system-ui、sans-serif，不下载字体。以下为 100% 缩放的逻辑尺寸，原生按屏幕 DPI 缩放。

| 角色 | 原生 pt | 浏览器 CSS px | 用途 |
| --- | --- | --- | --- |
| 辅助 | 9 | 12 | 提示、进度、状态说明 |
| 正文 | 10.5 | 14 | 按钮、菜单、输入、字段标签 |
| 小标题 | 12 | 16 | 插件面板标题、引导品牌与快捷键信息 |
| 页面标题 | 15 | 20 | 设置及引导主标题 |

常规按钮高 32，输入框高 40，菜单行高 36；控件圆角 8，内容面板圆角 12。标题栏图标及取词栏保留其紧凑尺寸，窗口外轮廓仍沿用既有圆角与缩放逻辑。

用户要求设置页字体再小两号后，设置采用同一主题的 `CompactFont` 变体：以上字号统一减少 1.5 pt，即 2 CSS px。设置正文 12、说明 10、标题 18；紧凑按钮高 30、按键框高 34。窗口由 440×644 缩至 380×536 DIP，并同步压缩标题、分组与左右留白。其余界面沿用表内字号。

主文字 `#2a313f`、辅助 `#677082`、强调 `#4366ee`、输入边界 `#838fa3`。白底对比分别为 13.05、4.98、4.80、3.27；正文达到 4.5，输入边界达到 3。选中态文字使用更深的 `#3352d6`，将浅蓝底上的对比从约 4.29 提高到 5.65。

## 交互

- 同类按钮共用悬停、按下、释放与焦点规则；悬停 120 ms、按下 60 ms、释放 90 ms。原生遵从 Windows 动画偏好，插件遵从 `prefers-reduced-motion`。
- 输入聚焦时使用连续蓝色边界，避免灰色边框与焦点环之间出现第二道间隙；禁用态保留可读文字。
- 插件入口展开后呈选中态；Esc 关闭并返回入口，空格可重新打开。
- 带入阶段强调“带入小窗”；回复可回填时强调“确认填回输入框”，只保留一个可用的主动作。草稿保护、确认回填和不自动发送的行为保持原样。
- 长标题在标题自身换行，关闭按钮固定；动作行允许换行，面板超高时内部滚动。
