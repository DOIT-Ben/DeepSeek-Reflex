# 回归检查

在项目根目录使用 PowerShell 7：

```powershell
pwsh -NoProfile -File .\webview-host\tests\run-tests.ps1
```

先离线构建，再分别编译普通 DPI 和应用 DPI manifest 的测试程序。Node.js 仅用于模拟输入框聚焦脚本，可以用 `-NodePath` 指定程序路径；运行应用和构建 C# 均不需要 Node.js。

`-OutputDirectory <绝对路径>` 可指定证据目录，默认写入系统临时目录的独立 GUID 子目录。日志、预览图、测试程序及隔离偏好不写入源码目录。

覆盖偏好迁移与保存、热键冲突回滚、设置动画、窗口模式、原生命中测试、托盘收起、缓存圆角像素与 HWND 同步、缩放时 GDI 对象数量。测试创建自有窗口并使用隔离偏好，不加载官网或操作已有浏览器。Windows 拒绝测试窗口前台权限时，该项明确标记 SKIP。

首次引导检查覆盖后台启动延后、首次主动唤起、真实模态窗口中暂停与恢复快捷键、已排队热键不隐藏主窗、当前配置显示、完成/跳过、设置中重看和无法写入完成标记时的恢复行为。引导与设置的自有控件预览图保存在测试输出目录。

弹窗圆角检查通过主窗口的真实设置和帮助入口，分别在取消置顶、置顶、再次取消置顶时打开模态弹窗。检查四个圆角 HWND 的原生可见性、所有者、实际置顶层级和前后堆叠顺序，移动后仍保持对齐且只上传四次缓存图片；关闭后主窗尺寸、白色边缘和快捷键注册正常。另通过自有 HWND 故障注入，验证圆角原生层级与 WinForms 属性不一致时的恢复；夹具按应用顺序在创建句柄前设置无边框样式。这些检查同时在普通和高 DPI 运行，补足仅检查图片或 WinForms 属性无法发现的遮挡问题。

交互打磨检查覆盖快捷键录入提示、无效与重复按键、真实排队 Esc / Tab 消息、分段选择的方向键导航、小尺寸面板滚动与固定保存区、取词栏不重叠与收起还原、开关按下后移出及置顶动画快速反转。普通和高 DPI 都保存设置及取词栏的自有控件预览；这些证据不代表已验证所有设备的物理键盘与跨屏 DPI 切换。

`focus-tests.cjs` 使用模拟 DOM，检查聚焦不会读取或改写草稿；结果不能代替登录、物理键盘或跨应用取词验收。历史性能基准和交付证据留在项目外的任务归档，回归入口不重复运行基准。
